Case study — EduRise Academy

Full-stack education platform

What it does

A complete website and enquiry workflow for a coaching institute. Visitors browse courses and send enquiries; the institute team manages every enquiry from one admin dashboard instead of scattered notebooks and chats. An admission chatbot answers common questions in a demo mode driven by a single knowledge-base file.

What was built

  • 11 public pages — home, courses, about, contact and more
  • Enquiry form with validation, saved to a real database
  • Admin dashboard with search, filters and status workflow
  • CSV export of enquiries for follow-up
  • Chatbot demo mode with an optional AI mode
  • Docker setup and a documented run book

Stack & verification

  • Next.js + TypeScript + Tailwind frontend
  • FastAPI + SQLAlchemy + SQLite backend, 15 API routes
  • Backend test suite passing (11/11)
  • Production build clean; 12/12 end-to-end browser checks passed
  • Fresh-clone audit: tables auto-create, no secrets committed
The workflow it replaces manual registers with Student enquiry→ Validation→ Admin dashboard→ Status tracking→ CSV export

Case study — DocuMind AI

AI document chatbot · Strict RAG

What it does

A question-answering tool for your own documents. Upload PDFs, ask questions in plain language, and get answers drawn only from those documents — each with the page it came from. When the answer is not in the documents, it says so plainly instead of inventing one.

What was built

  • PDF upload and text extraction with PyMuPDF
  • Chunking and embedding into a ChromaDB vector index
  • Strict retrieval — answers grounded in retrieved passages only
  • Page-level citations attached to every answer
  • React 19 + TypeScript chat interface
  • A real recorded demo, available in the repository

Stack & verification

  • Python + FastAPI backend
  • PyMuPDF for extraction, ChromaDB for retrieval
  • React 19 + TypeScript frontend
  • Tested end to end, including the “not found” behaviour
  • Documented setup so anyone can run it from the repo
How an answer is produced PDF upload→ Text extraction→ Vector index→ Question→ Answer + page citation
